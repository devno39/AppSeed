# Brainstorms

Requirements documents for **this app**, dated:
`YYYY-MM-DD-<topic>-requirements.md`. Start from `../templates/brainstorm-template.md`.

A brainstorm frames the problem before anything is built and lands numbered
requirements the plan can trace back to. Decisions get recorded here with their
reasoning, so the plan does not have to re-argue them.

The folder is empty on a fresh clone.
