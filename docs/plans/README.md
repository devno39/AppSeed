# Plans

Implementation plans for **this app**, one file per piece of work, dated:
`YYYY-MM-DD-NNN-<type>-<topic>.md`. Start from `../templates/plan-template.md`.

A plan turns a brainstorm's numbered requirements into ordered, atomic steps and
records the decisions taken along the way — including the ones that were rejected,
which is usually the part worth re-reading.

The folder is empty on a fresh clone. The seed's own build record lives in
`../harvest/`.
