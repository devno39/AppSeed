# Reviews

Project-wide review reports for **this app**, dated:
`YYYY-MM-DD-<scope>-review.md`. Start from `../templates/review-template.md`.

Findings are grouped by severity and carry a checkbox so they can be struck as
they ship. Every medium-or-worse finding cites a real `File.swift:line` and is
adversarially verified before it earns one — a finding that cannot be reproduced
is refuted, not listed.

The folder is empty on a fresh clone. The seed's own review record lives in
`../harvest/`.
