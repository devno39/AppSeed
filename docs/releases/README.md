# Releases

Shipped notes for **this app**, one file per version: `vX.Y.Z.md`. Start from
`../templates/release-template.md`.

Write it in the same commit that ships the version — what shipped in the user's
terms, plus the load-bearing technical facts (migration numbers, new tables,
widget kinds, limits) and any same-day post-release action such as raising
`app_config.minimum_supported_version`.

The folder is empty on a fresh clone.
